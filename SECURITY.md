# Security Policy

`swift-node` generates and compiles native code, so malformed generated code can
be more serious than an ordinary JavaScript bug.

Please report vulnerabilities through GitHub Security Advisories for this
repository once it is public. If advisories are not available yet, contact the
maintainer privately before opening a public issue.

Include:

- affected package and version
- minimal Swift and JavaScript reproduction
- platform, CPU architecture, Node version, Swift version, and macOS version
- whether the issue requires running untrusted Swift source

Please do not publish exploit details until a fix is available.
